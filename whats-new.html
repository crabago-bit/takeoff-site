Everything that's landed in Groundwork Takeoff, newest first. Subscribers and maintenance-plan owners get every one of these automatically.

August
2026 · v0.5.0

Cloud drive live links New

Open plan sets straight from Google Drive, Dropbox, OneDrive, or SharePoint — the document stays linked to its source, and when the file changes upstream the app offers to reload it. Your markups and takeoffs survive the update.

Batch suite New

Run operations across whole plan sets in one pass: batch export, batch calibration, slip-sheeting revisions, transferring markups to a new set, page-image comparison, and more — with a live queue you can cancel anytime.

Markups list, rebuilt as a data grid New

Filter by any column, save custom views per project or document, see running totals, and jump from any row straight to its markup on the sheet — it flashes so you can't miss it.

Floating selection toolbar New

Select one or many markups and the tools you need appear right at the selection — restyle, duplicate, align, or delete in place. Batch edits are one undo step, so experiments are safe.

Faster measuring: drag-to-draw, marquee select, and full editing Improved

Draw measurements by dragging, finish with a right-click, box-select multiple items, then move, resize, or adjust individual corners — every edit is exactly one undo step.

Per-page scale calibration Improved

Every page can carry its own scale (details and plans in one set, no problem), and an amber "Scale Not Set" badge warns you before you ever measure on an uncalibrated sheet.

Tool Chest: Recent tools + 1–9 hotkeys New

Every tool you use is auto-captured to Recents; promote favorites to My Tools and they get number-key hotkeys — your whole kit, one keystroke away.

Rebindable keyboard shortcuts New

Every action's shortcut is yours to change in Settings, with conflict warnings and one-click reset. Muscle memory from your last tool comes with you.

Zoom cluster + live coordinate readout Improved

A zoom slider and editable percentage live in the status bar, alongside a live cursor readout in real calibrated feet — you always know exactly where and how big.

Copy/paste that understands takeoffs Improved

Paste whole selections — across pages, even across documents — and quantities re-price against the destination page's scale automatically.

Automation API & CAD connections New

A built-in scripting panel automates repetitive document work, and new secure API tokens let CAD tools publish sheets directly into your library — including a Revit add-in for pushing sheet sets from the model.

Organize Pages view New

A full-screen thumbnail grid for whole-set page work: drag to reorder, rotate, duplicate, delete, insert between pages, and extract — with familiar click, Ctrl, and Shift selection.

Apply Redactions — permanent, on a new file Improved

Redaction now has the two-step shape it deserves: mark anywhere, then Apply in the desktop app to permanently remove the marked content into a new -redacted copy — with a clear warning before anything is irreversible, and your original file untouched.

Add Text: click and type Improved

Adding text to a PDF is now what you'd expect: click where you want it, type, press Enter. A small options row sets size and color (and remembers your last choice) — no more coordinate forms.

A cleaner Page tab Improved

Page tools are reorganized into task groups — File, Organize, Edit, Protect, Export — and Watermark, Bates numbering, Header & Footer, and Combine now open directly from the ribbon instead of hiding inside a hub dialog. Every dialog also shares one consistent look.

July
2026

Cloud Library New

Your plan sets now follow you. Open a set at the office, pick it up on the laptop or iPad — same document, same takeoffs, synced automatically in the background. Documents are matched by their content, so the same PDF is recognized as the same document on every device, even after edits.

Steadier live collaboration on big sets Improved

Multi-sheet sessions got a rebuilt engine under the hood: each sheet now syncs independently, so two estimators working a 200-page set see each other's markups faster and more reliably.

PDF compression, PDF/A, and Office conversion New

Shrink bloated scan sets down to emailable sizes, export archival PDF/A for closeout, and drop Word/Excel/PowerPoint files straight into the app — they convert to PDF and join your set.

Markup rotation + editing polish Improved

Rotate any markup freely. Right-click menus, layering (bring-to-front / send-to-back), and the properties editor all got cleaned up, and the sidebar is now resizable.

Support center & seat management New

A proper support portal is live — submit questions or bug reports from the website and a human replies, usually same day. Companies on team plans can now have seats assigned and managed per person.

Set as default PDF app on macOS New

Double-click any PDF in Finder and it opens in Groundwork Takeoff.
